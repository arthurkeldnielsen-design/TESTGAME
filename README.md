# 🏁 3D Racing Game

A fully functional 3D racing game that runs directly in your browser!

## Features

✨ **Complete 3D Racing Experience**
- Beautiful 3D graphics with proper lighting and shadows
- Smooth car physics and handling
- Circular track with lap detection
- Real-time speedometer and lap counter

🎮 **Easy Controls**
- **Arrow Keys** or **WASD** - Control the car
- **Space** - Reset car position
- Intuitive camera that follows the car

🏆 **Gameplay**
- Complete 3 laps around the track
- Timer tracks your race time
- Visual HUD with speed, lap count, and position
- Game over screen with final time

## How to Play

1. Open `index.html` in your web browser
2. Click "START GAME" to begin
3. Use arrow keys or WASD to control your car:
   - **↑/W** - Accelerate
   - **↓/S** - Brake
   - **←/A** - Turn Left
   - **→/D** - Turn Right
4. Complete 3 laps around the circular track
5. View your final time when you cross the finish line

## Technical Details

**Built with:**
- Three.js - 3D graphics library
- Vanilla JavaScript - Game logic
- HTML5 Canvas - Rendering

**Game Features:**
- Dynamic lighting and shadows
- Collision detection with track boundaries
- Realistic car physics and friction
- Lap counting system with checkpoints
- Responsive camera system
